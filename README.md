
# proxy_agregator

> Агрегатор Xray-конфигов (VMess, VLESS, Trojan) для доступа к заблокированным ресурсам и анонимности.

Проект собирает, валидирует и ротирует конфиги из открытых источников.  
Работает как **поставщик конфигов для Xray**, который превращает их в рабочие SOCKS5/HTTP-туннели.

---

## 🎯 Зачем это нужно

- Доступ к ресурсам, которые заблокированы в твоей стране.
- Единый шлюз для браузера, скриптов и приложений.
- Автоматическая ротация: мёртвые прокси отсеиваются, рабочие остаются.

---

## 🏗️ Архитектура

```

Открытые источники (VMess / VLESS / Trojan)
↓
Агрегатор (Python)
├── сбор конфигов
├── валидация
├── хранение в Redis
└── восстановление после сбоя
↓
Xray-core
├── принимает SOCKS5/HTTP от клиента
├── превращает в VMess/VLESS/Trojan
└── отправляет через выбранный прокси
↓
Целевой ресурс

```

- **Агрегатор** — собирает и валидирует конфиги, хранит состояние в Redis.
- **Xray** — исполняет: превращает SOCKS5/HTTP в VMess/VLESS/Trojan и гонит трафик через прокси.
- **Клиент** (браузер, скрипт, программа) — работает через единый SOCKS5/HTTP-порт Xray.

---

## 🛡️ Отказоустойчивость

- **Состояние хранится в Redis** — процесс не теряет прогресс при падении.
- **Идемпотентная обработка** — при перезапуске агрегатор получает те же списки, но обрабатывает только необработанные прокси.
- **Сброс базы** — можно обнулить состояние и начать с чистого листа.
- **Восстановление после сбоя** — агрегатор продолжает с точки останова, а не начинает заново.

```
├── server_flask.py     # Flask-сервер (в разработке)
└── requirement.txt     # зависимости

```
